## 3. Môi trường phát triển

* Node.js
* npm
* Visual Studio Code
* Git / GitHub
* MongoDB

---

## 4. Chạy dự án

### Frontend

```bash
cd FRONT_END
npm install
npm run dev
```

### Admin

```bash
cd ADMIN
npm install
npm run dev
```

### Backend

```bash
cd BACK_END
npm install
npm run dev
```

---

## 5. Database

Database sử dụng **MongoDB**.

Backend kết nối MongoDB thông qua **Mongoose**.

Thông tin kết nối được lưu trong file:

```text
.env
```

Không đưa `.env` lên GitHub.

---

## 6. Git

Các thư mục/file không commit:

```text
node_modules/
.env
dist/
```

Sử dụng GitHub để quản lý source code và tài liệu dự án.
